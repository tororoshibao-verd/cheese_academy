# ①課題名

チーズアカデミー課題（制作作品「しばお じゅんき 友だち募集中」）

## ②課題内容

柴尾準輝の自己紹介と友だち募集を兼ねた1ページのWebサイトです。デザインやものづくり、東京ヴェルディの観戦、中野・昭和新道での飲み歩きなど、交流のきっかけになる話題を紹介しています。プロフィールや制作中・構想中の作品、よくある質問を掲載し、LINEの友だち追加へ案内しています。

HTMLとCSSで実装しています。ローカルでは `index.html` をブラウザで開くと閲覧できます。

## ⑤工夫した点・こだわった点

- ページ内リンクから「メリット」「どんな人？」「よくある質問」へ移動できるようにし、LINEの友だち追加ボタンをページ内の複数箇所に配置しました。
- スマートフォンでは縦に並べ、画面幅が900px以上ではメインビジュアルの文章とイラストや、メリットのカードを横並びに切り替えています。
- プロフィール写真は、同じ写真の組を2つ並べ、CSSアニメーションで繰り返し横に流しています。昭和新道の紹介カードにはGoogle マップを埋め込んでいます。

## ⑥難しかった点・次回トライしたいこと（又は機能）

- SlackのDMボタンには仮のリンクが設定されています。実際のDMリンクへの差し替えが残っています。
- 問い合わせフォームはデモ表示で、送信ボタンは無効です。送信先の実装が残っています。
